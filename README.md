# -plp-da-a2-rainfall-advisory

## Project Summary
This project focuses on cleaning raw monthly rainfall readings for five Kenyan counties (Nairobi, Nakuru, Kisumu, Mombasa, and Machakos), utilizing NumPy to perform rapid, vectorized analyses, and outputting an agricultural planting advisory based on historical patterns.

## How to Run the Notebook
1. Ensure you have Python 3 installed along with the libraries listed in `requirements.txt` (install via `pip install -r requirements.txt`).
2. Open `rainfall_analysis.ipynb` in Google Colab or your local Jupyter Notebook server.
3. Run all cells sequentially from top to bottom to execute the cleaning pipeline, compute metrics, and export the summary CSV.

## Planting Advisory
* Farmers in Nairobi, Nakuru, Kisumu, and Mombasa should align their primary cropping cycles with the optimal April-May planting window to maximize yields from seasonal rainfall peaks.
* Machakos County requires specialized agricultural strategies due to high dryness risks (6 dry months) and a distinct late-year planting window in November-December.
* High reliance on supplementary irrigation and water-harvesting systems is recommended for arid counties such as Machakos and Mombasa to mitigate drought vulnerabilities.
